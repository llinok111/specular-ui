UPSTREAM

This project is an independent extension of, and includes code derived from:

  liquid-glass-react
  https://github.com/rdev/liquid-glass-react
  Copyright (c) 2025 MAX ROVENSKY
  License: MIT

  Files derived from the upstream project:
    src/index.tsx          (upstream React component, kept for reference)
    src/shader-utils.ts    (upstream SDF displacement generator)
    src/utils.ts           (upstream pre-generated displacement maps)
    src/core/sdf.js        (ported; makeLensFragment / roundedRectSDF /
                            smoothStep carry the upstream maths, with the
                            parameterisation and neutral-region skip added here)

  Upstream's own attribution, preserved verbatim in src/shader-utils.ts:
    "Adapted from https://github.com/shuding/liquid-glass"

  This repository retains the upstream commit history (16 commits, original
  authors and dates). Two asset files (assets/video.mov, 80 MB and
  assets/project-liquid.gif, 16 MB) were removed from history to keep the
  repository clonable; no source file was altered by that rewrite.

ORIGINAL WORK IN THIS REPOSITORY
===============================================================================

Copyright (c) 2026 specular-ui contributors, MIT. Principal additions:

  src/core/capability.js     capability probe, four-tier decision table,
                             frame governor with single-downgrade semantics
  src/core/light.js          document-wide light controller: pointer tracking,
                             idle drift, azimuth derivation, per-element lobe
  src/core/materials.js      material registry and ambience presets
  src/core/displacement.js   refraction atlas: size quantisation, resolution
                             cap, LRU filter sharing
  src/core/sdf.js            makeBoxLens (pixel-space lens), makeDoubleLensFragment,
                             makeGrazingFragment, computeDisplacementField
  src/elements/*             sp-button, sp-card, sp-panel, sp-navbar and the
                             shared light-DOM base class
  src/styles/*               token system, four-material CSS optics, element shell
  demo/, docs/, test/        demonstration, documentation, 68 tests

===============================================================================
THIRD-PARTY RUNTIME CODE
===============================================================================

None. The shipped bundles have no runtime dependencies. Build and test
dependencies (esbuild, playwright, pngjs) are development-only and are not
included in dist/ or in the release ZIP.
