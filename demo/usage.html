使用文档

两个文件，四行 HTML。组件是原生自定义元素，主题是 CSS 变量，光源是整个文档共享的一条向量。

安装 初始化 按钮 卡片 面板 导航 控件 主题变量 光照 降级 移动端 无障碍 常见问题

安装

<link rel="stylesheet" href="specular-ui.css">
<script type="module" src="specular-ui.js"></script>

两个文件，不需要构建步骤、不需要 peer dependency。dist/ 里的产物可直接放到静态服务器。

初始化

导入即初始化：探测能力、设定档位、接管光源。要延后启动，在 <html> 上加 data-sp-auto="false" 后手动调用：

import { init, diagnostics } from "specular-ui";

const { tier, tierLabel, reasons } = init({ tier: 0, tilt: false });
console.table(diagnostics());

data-sp-ambience 决定光由什么构成，因此决定反射长什么样：

import { setAmbience } from "specular-ui";

<sp-button>

内部是真实的 <button>，所以在 <form> 内会正常提交，键盘、焦点顺序全部由平台提供。

主要 描边 幽灵 危险 禁用 载入 
<sp-button material="liquid" variant="primary" size="lg">开始</sp-button>
<sp-button type="submit" form="save-form" loading>提交中</sp-button>
属性取值说明
materialliquid / metal / frost / holo表面材质
variantprimary / outline / ghost / danger语义变体
sizesm / md / lg / xl尺寸
disabled loading布尔同时同步 aria 状态
type form label字符串转发给内部按钮

不要在已挂载的组件上写 textContent，那会替换掉内部结构。请改插槽里的元素。

表单控件

四个更常见的控件，内部同样是真实元素：<button role="tab">、<label for> + <input>、<button role="switch">、原生 <dialog>。

<sp-tabs material="frost" value="材质">
  <div data-tab="材质">面板一</div>
  <div data-tab="组件">面板二</div>
</sp-tabs>

方向键循环切换，Home / End 跳首尾；只有当前标签在 Tab 序列里（roving tabindex），所以 Tab 会整组跳过。

role="tablist" / "tab" / "tabpanel"，配 aria-selected、aria-controls、aria-labelledby。这三条是手写标签页最常漏的，测试里逐条断言。
打开对话框 
<sp-input material="frost" label="邮箱" type="email" placeholder="you@example.com"></sp-input>
<sp-switch material="metal" label="自动漂移" checked></sp-switch>

<sp-dialog material="liquid" heading="放弃更改？">
  <p>未保存的内容会丢失。</p>
  <div data-slot="actions">
    <sp-button variant="ghost" data-close>取消</sp-button>
    <sp-button variant="danger" data-confirm>放弃</sp-button>
  </div>
</sp-dialog>

对话框用原生 <dialog>：焦点困在内部、Esc 关闭、背景 inert、进入 top layer 都由平台提供。材质加在对话框内部 —— 带滤镜的元素进入 top layer 会自己成为包含块，背景就看不到了。

未保存的材质参数会丢失。

主题变量

全部以 --sp- 开头，覆盖任意一个即可。

变量默认作用
--sp-lx --sp-ly0.32 / 0.18光源位置（JS 写入）
--sp-angle135deg方位角，conic-gradient 直接用
--sp-frost-blur18px主体模糊半径
--sp-aberration0.55色边强度，0 关闭
--sp-tint-strength0.16环境色浸染
--sp-noise-opacity0.34磨砂颗粒
--sp-holo-saturation85%全息色谱饱和度
--sp-metal-brush3px拉丝间距
/* 更冷、更薄、更锐利 */
[data-material="liquid"] {
  --sp-frost-blur: 8px;
  --sp-tint-strength: 0.08;
  --sp-aberration: 0.3;
}

光照

指针即光源；静止 2.6 秒后开始缓慢漂移。

import { light } from "specular-ui";

light.set(0.2, 0.8);      // 手动定位
light.lock(true);         // 冻结
light.detach();           // 停止
await light.enableTilt(); // 手机倾斜（iOS 需手势）

任何带 data-sp-lobe 的元素都会获得指针在自身内部的位置：

<div data-sp-lobe class="panel">…</div>

.panel::after {
  background: radial-gradient(120% 90% at var(--sp-mx) var(--sp-my), #fff3, transparent 60%);
}

降级

档位data-sp-tier保留
full0全部
balanced1半强度模糊、弱色边，关闭噪点与漂移
lite2仅一层背景模糊
static3纯色板 + 发丝边，零合成
full balanced lite static

prefers-reduced-transparency、prefers-reduced-motion、粗指针、低内存设备各自映射到一个档位，无需手动处理。

移动端

已内置，无需配置：粗指针下所有交互元素 ≥ 44×44；720px 以下导航收起品牌文字；560px 以下内边距收紧；prefers-reduced-transparency 直接跳 light 档。

倾斜控制需要用户手势授权，因此永不自动启用。

无障碍

每个组件内部都是语义正确的原生元素；焦点环用 outline 且带 offset；disabled / loading 同步 aria-disabled / aria-busy；面板标题带 aria-expanded。高对比模式下发丝边加粗。

常见问题

为什么玻璃没有"扭曲"背景？

浏览器不会把 backdrop-filter 的结果送进 filter: url(#…)，所以基于位移贴图的几何折射对玻璃表面无效。本库用"边缘梯度模糊 + 色散"营造厚度。详见仓库 docs/LIMITS.md。

React / Vue 能用吗？

能，自定义元素与框架无关。React 19 以下对自定义元素属性支持有限，复杂属性用 ref 设置。

SSR 会报错吗？

不会。所有 DOM 访问都在环境检测之后。
